# RIS 天线阵列 PCB 设计指南

> **本文档提供完整的 PCB 设计规范,可直接用于打板生产**

---

## 📐 设计规格

### 基本参数
- **工作频率**: 10.5 GHz (可适配至 16.7 GHz)
- **阵列规模**: 8×8 = 64 单元
- **单元间距**: λ/2 ≈ 14.3 mm (@ 10.5 GHz)
- **阵列尺寸**: ~100 mm × 100 mm
- **板材**: Rogers 4350B + 4003C 混合叠层

### 叠层结构 (6 层金属 + 5 层介质)

```
Layer Stackup (Top to Bottom):
┌─────────────────────────────────────┐
│ Layer 1: Top Copper (辐射贴片)       │  ← 铜厚 35 μm (1 oz)
├─────────────────────────────────────┤
│ Dielectric 1: Rogers 4350B          │  h = 0.508 mm, εr = 3.48
├─────────────────────────────────────┤
│ Layer 2: Ground Plane 1             │  ← 完整接地层
├─────────────────────────────────────┤
│ Dielectric 2: Rogers 4450F          │  h = 0.102 mm (粘接层)
├─────────────────────────────────────┤
│ Layer 3: DC Control Lines 1         │  ← Vpin 控制线
├─────────────────────────────────────┤
│ Dielectric 3: Rogers 4350B          │  h = 0.508 mm, εr = 3.48
├─────────────────────────────────────┤
│ Layer 4: DC Control Lines 2         │  ← Vvar 控制线
├─────────────────────────────────────┤
│ Dielectric 4: Rogers 4450F          │  h = 0.102 mm (粘接层)
├─────────────────────────────────────┤
│ Layer 5: Ground Plane 2             │  ← 馈电网络地层
├─────────────────────────────────────┤
│ Dielectric 5: Rogers 4003C          │  h = 0.508 mm, εr = 3.38
├─────────────────────────────────────┤
│ Layer 6: Bottom Copper (馈电网络)    │  ← 微带馈线
└─────────────────────────────────────┘

总厚度: ~2.74 mm
```

## 🎨 天线单元设计

### 单元结构

每个 RIS 单元包含:
1. **辐射贴片**: 矩形微带贴片 (尺寸根据谐振频率计算)
2. **PIN 二极管**: MA4P7454B-402T (实现 0°/180° 切换)
3. **变容二极管**: SMV1235-083LF (实现 0°~180° 连续调谐)
4. **直流偏置电路**: RF 扼流电感 + 去耦电容

### 关键尺寸计算

**辐射贴片尺寸** (基于传输线模型):

```
W = c / (2 * f0 * sqrt((εr + 1) / 2))
L = c / (2 * f0 * sqrt(εeff)) - 2 * ΔL

其中:
  c = 光速 = 3e8 m/s
  f0 = 10.5 GHz
  εr = 3.48 (Rogers 4350B)
  εeff ≈ (εr + 1) / 2 = 2.24
  ΔL ≈ 0.412h * (εeff + 0.3) * (W/h + 0.264) / ((εeff - 0.258) * (W/h + 0.8))

计算结果:
  W ≈ 6.8 mm
  L ≈ 5.2 mm
```

### 布局规则

```
Unit Cell Layout (俯视图):

┌──────────────────────────┐
│     辐射贴片 (6.8×5.2mm)  │
│                          │
│   ┌────┐    ┌──────┐    │
│   │PIN │    │VarCap│    │
│   └────┘    └──────┘    │
│      │          │        │
│   [RF Choke] [DC Block]  │
│      │          │        │
│   ───┴──────────┴───     │  ← 微带馈线 (Layer 6)
└──────────────────────────┘

单元间距: 14.3 mm (λ/2 @ 10.5 GHz)
```

## 🔌 馈电网络设计

### 威尔金森功分器 (1分64)

**设计方法**: 多级 1分2 级联

```
输入 ──→ [1分2] ──→ [1分2] ──→ [1分2] ──→ ... (6级) ──→ 64路输出
                ├─→ [1分2] ──→ ...
                └─→ [1分2] ──→ ...
```

**单级 1分2 威尔金森功分器参数**:

| 参数 | 值 | 说明 |
|-----|-----|------|
| 特性阻抗 Z0 | 50 Ω | 输入/输出端口 |
| 分支阻抗 Z1 | 70.7 Ω | Z0 × √2 |
| 隔离电阻 R | 100 Ω | 2 × Z0 |
| 微带线宽度 W | 1.14 mm | Rogers 4350B, h=0.508mm |
| 四分之一波长长度 | 7.1 mm | @ 10.5 GHz |

**PCB 布局要点**:
1. **对称性**: 两分支必须严格对称,长度误差 < 0.1 mm
2. **隔离电阻**: 使用 0603 封装 100Ω ±1% 精密电阻
3. **T 型结**: 添加补偿电容 (0.2 pF) 改善匹配
4. **接地过孔**: 每 λ/10 放置一个接地过孔 (直径 0.3 mm)

### 反射型移相器

**电路拓扑**:

```
        ┌─────────────────┐
输入 ──→│  90° 混合耦合器   │──→ 输出
        │                 │
        │  ┌───────────┐  │
        └─→│ VarCap    │←─┘
           └───────────┘
              │
             GND
```

**关键参数**:
- **耦合度**: 3 dB (等分)
- **相位差**: 90° (两输出端口)
- **回波损耗**: < -15 dB
- **插入损耗**: < 2 dB

**实现方式**:
- 使用 Lange 耦合器或分支线耦合器
- 变容二极管接在隔离端口
- 通过调节 Vvar (0-10V) 改变等效电容,实现相位调谐

## 🛠️ 制造工艺要求

### PCB 厂家选择

**推荐厂家**:
- 国内: 嘉立创 (JLCPCB)、捷配 (NextPCB)
- 国际: PCBWay、AllPCB

**下单参数**:
```
板材: Rogers 4350B + 4003C (高频板材)
层数: 6 层
铜厚: 1 oz (35 μm)
最小线宽/间距: 0.15 mm / 0.15 mm
最小过孔: 0.3 mm (钻孔) / 0.6 mm (焊盘)
表面处理: ENIG (化学镍金, 适合高频)
阻抗控制: 是 (50 Ω ±10%)
测试: 100% 电气测试
```

### 关键工艺注意事项

1. **阻抗控制**
   - 微带线宽度公差: ±0.05 mm
   - 介电常数公差: ±0.05
   - 要求厂家提供阻抗测试报告

2. **过孔设计**
   - 盲埋孔: 不需要 (全通孔即可)
   - 过孔间距: ≤ λ/10 ≈ 2.8 mm
   - 填充: 非导电填充 (避免影响 RF 性能)

3. **焊接要求**
   - PIN/变容二极管: 手工焊接或回流焊 (温度曲线需优化)
   - SMA 连接器: 垂直安装,确保良好接地

## 🔧 装配指南

### 焊接顺序

1. **先贴无源器件**
   - 电阻、电容、电感
   - 使用回流焊

2. **再焊有源器件**
   - PIN 二极管 (注意极性!)
   - 变容二极管 (注意极性!)
   - 建议手工焊接,便于检查

3. **最后安装连接器**
   - SMA 射频接口
   - USB/JTAG 接口

### 焊接注意事项

**PIN 二极管焊接**:
- 温度: 250-280°C
- 时间: < 5 秒/引脚
- 先焊一侧,再焊另一侧
- 使用显微镜检查焊点

**变容二极管焊接**:
- 同上,但更敏感
- 避免静电 (佩戴防静电手环)
- 焊接后立即测试电容值

## 🧪 测试验证

### 单板测试 (未组装 FPGA/STM32)

1. **直流测试**
   ```
   - 测量各电源轨对地电阻 (应 > 1 kΩ)
   - 施加 3.3V,测量静态电流 (< 10 mA)
   ```

2. **RF 测试**
   ```
   - 使用 VNA 测量 S11 (@ 10.5 GHz)
   - 预期: S11 < -10 dB
   ```

### 系统联调

1. **烧录 FPGA 比特流**
2. **启动 STM32 固件**
3. **运行 Python GUI**
4. **测试波束扫描**
5. **验证目标检测**
