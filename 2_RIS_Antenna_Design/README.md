# RIS 天线阵列设计指南

## 概述

本目录包含基于智能超表面(RIS)技术的 8×8 天线阵列完整设计文件，采用六层金属与五层介质复合叠层架构，实现 360° 相位连续可调。

## 设计规格

### 工作频率
- **中心频率**: 10.5 GHz (可适配至 16.7 GHz)
- **带宽**: 800 MHz (10.1-10.9 GHz)

### 阵列参数
- **单元数量**: 64 (8×8)
- **单元间距**: λ/2 ≈ 14.3 mm (@ 10.5 GHz)
- **阵列尺寸**: ~100 mm × 100 mm
- **波束扫描范围**: ±60° (方位角和俯仰角)

### 性能指标
- **回波损耗**: < -10 dB
- **增益**: ≥ 9.8 dBi
- **副瓣电平**: < -12 dB
- **波束指向误差**: < 1°

## 天线单元设计

### 复合叠层结构

```
六层金属 (自上而下):
┌─────────────────────────┐
│ Layer 1: 辐射贴片层      │  ← PIN 二极管 + 变容二极管
├─────────────────────────┤
│ Layer 2: 辐射贴片地层    │
├─────────────────────────┤
│ Layer 3: DC 控制线层 1   │  ← Vpin 控制线
├─────────────────────────┤
│ Layer 4: DC 控制线层 2   │  ← Vvar 控制线
├─────────────────────────┤
│ Layer 5: 馈电网络地层    │
├─────────────────────────┤
│ Layer 6: 馈电网络层      │  ← 微带馈线
└─────────────────────────┘

五层介质 (自上而下):
┌─────────────────────────┐
│ Rogers 4350B (h=0.508mm)│  εr=3.48, tanδ=0.0037
├─────────────────────────┤
│ Rogers 4450F (h=0.102mm)│  粘接层
├─────────────────────────┤
│ Rogers 4350B (h=0.508mm)│  εr=3.48, tanδ=0.0037
├─────────────────────────┤
│ Rogers 4450F (h=0.102mm)│  粘接层
├─────────────────────────┤
│ Rogers 4003C (h=0.508mm)│  εr=3.38, tanδ=0.0027
└─────────────────────────┘
```

### 关键器件

#### 1. PIN 二极管 (高速开关)
- **型号**: MA4P7454B-402T (MACOM)
- **功能**: 实现 0°/180° 快速切换
- **参数**:
  - 正向电压: 0.7-1.0 V
  - 反向击穿电压: ≥ 50 V
  - 开关时间: < 10 ns
  - 串联电阻: 2-4 Ω (正向)

#### 2. 变容二极管 (连续调谐)
- **型号**: SMV1235-083LF (Skyworks)
- **功能**: 实现 0°~180° 连续相移
- **参数**:
  - 电容范围: 0.3-2.5 pF (@ 0-10V)
  - Q 值: > 100 (@ 10 GHz)
  - 反向击穿电压: ≥ 15 V

### 单元电路原理

```
         ┌──────────────┐
         │  辐射贴片     │
         │              │
    Vpin─┤──[PIN Diode]─┤── GND
         │              │
    Vvar─┤──[VarCap]────┤── GND
         └──────────────┘
              │
         [微带馈线]
              │
         [功分器输出]
```

**工作原理**:
1. **PIN 二极管**: 通过 Vpin 控制通断状态，实现 1 比特相位重构 (0°/180°)
2. **变容二极管**: 通过 Vvar (0-10V) 调节等效电容，实现连续相位调谐
3. **协同调控**: 结合两者可实现 360° 全相位连续可调

## 馈电网络设计

### 威尔金森功分器 (1分64)

采用多级 1分2 威尔金森功分器级联：

```
输入 ──→ [1分2] ──→ [1分2] ──→ [1分2] ──→ ... ──→ 64 路输出
                ├─→ [1分2] ──→ ...
                └─→ [1分2] ──→ ...
```

**设计参数**:
- **层数**: 6 级 (2^6 = 64)
- **特性阻抗**: 50 Ω (输入/输出), 70.7 Ω (隔离电阻支路)
- **隔离电阻**: 100 Ω (每级)
- **回波损耗**: < -16 dB
- **端口隔离度**: < -23 dB

### 反射型移相器

每个天线单元对应一个独立的反射型移相器：

```
        ┌─────────────┐
输入 ──→│  90° 混合耦合器 │──→ 输出
        │             │
        │  ┌───────┐  │
        └─→│VarCap │←─┘
           └───────┘
              │
             GND
```

**工作原理**:
- 输入信号经 90° 混合耦合器分为两路
- 一路经变容二极管反射，相位随电容变化
- 另一路作为参考
- 两路重新合成后实现 0°~180° 连续相移

**性能**:
- **相移范围**: > 185.5° (@ 16.7 GHz)
- **插入损耗**: < 2 dB
- **回波损耗**: < -15 dB

## PCB 设计要点

### 布局原则

1. **对称性**: 功分器各级保持严格对称，确保幅度平衡
2. **隔离**: RF 走线与 DC 控制线保持 ≥ 3× 线宽间距
3. **接地**: 多层过孔阵列确保良好接地 (via spacing ≤ λ/10)
4. **阻抗匹配**: 所有 RF 走线严格控制 50 Ω 特性阻抗

### 制造工艺

- **板材**: Rogers 系列高频板材
- **铜厚**: 1 oz (35 μm)
- **最小线宽/间距**: 0.15 mm / 0.15 mm
- **过孔直径**: 0.3 mm (钻孔) / 0.6 mm (焊盘)
- **表面处理**: ENIG (化学镍金)

## 仿真验证

### 天线单元仿真 (HFSS/CST)

**仿真设置**:
- **求解器**: Driven Modal (频域)
- **边界**: Open (Add Space)
- **激励**: Wave Port

**验证项目**:
1. **S11 参数**: < -10 dB (@ 10.5 GHz)
2. **方向图**: 主瓣增益、副瓣电平、波束宽度
3. **相位响应**: Vpin/Vvar 扫描下的相位变化曲线
4. **互耦效应**: 相邻单元间 S21 参数

### 阵列仿真

**方法**: 阵列因子法 + 全波仿真验证

**验证项目**:
1. **波束扫描**: ±60° 范围内增益变化 < 3 dB
2. **副瓣电平**: 所有扫描角度下 < -12 dB
3. **栅瓣抑制**: 无栅瓣出现

## 常见问题

### Q1: 相位调控非线性怎么办？

**A**: 
- 增加校准算法补偿非线性
- 选择高 Q 值变容二极管
- 预留冗余调控范围 (设计 0-200°, 实际使用 0-180°)

### Q2: 互耦效应影响方向图？

**A**:
- 优化单元间距 (≥ λ/2)
- 引入去耦结构 (缺陷地、电磁带隙)
- 仿真时计入互耦效应并优化

### Q3: 焊接 PIN/变容二极管困难？

**A**:
- 使用热风枪 (温度 250-280°C)
- 先焊接一侧引脚，再焊接另一侧
- 使用显微镜检查焊接质量
